# MSBA Used Device Analysis

## Overview
This project analyzes a dataset of used electronic devices using Python. The purpose of the assignment was to practice data analysis techniques using pandas, NumPy, and data visualization while identifying patterns and outliers in used device data.

## Analysis
The notebook:
- Identifies missing values and limitations within the dataset.
- Uses boxplots to identify outliers in relevant numerical variables.
- Calculates device age using release year.
- Examines the relationship between normalized new price and normalized used price using a scatterplot and correlation.
- Uses NumPy to calculate descriptive statistics and percentiles.
- Randomly samples devices from the dataset.
- Uses z-scores to identify outliers in normalized used price.
- Compares days used, internal memory, and weight between price outliers and the full dataset.
- Uses visualizations to compare characteristics of the identified outliers.
